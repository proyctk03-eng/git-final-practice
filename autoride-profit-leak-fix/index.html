Bảo Vệ Thiết Kế - Giải Đáp 3 Câu Hỏi Vấn Đáp Giảng Viên

Câu hỏi 1: Tại sao tách Inspections ra bảng riêng lại tốt hơn việc nhồi nhét cột damage_description trực tiếp vào bảng Rentals?

Trả lời:
1. Chuẩn hóa dữ liệu: Tránh lãng phí dung lượng lưu trữ các trường NULL khi xe trả nguyên vẹn.
2. Lưu vết đa thời điểm (1-N): Một vòng đời thuê xe có ít nhất 2 mốc kiểm tra (lúc nhận xe và lúc trả xe). Nếu chỉ có 1 cột trong Rentals, kết quả kiểm tra lần sau sẽ ghi đè lên lần trước, xóa mất bằng chứng pháp lý ban đầu.
3. Khả năng mở rộng: Bảng riêng cho phép lưu trữ nhiều ảnh giám định, nhiều hạng mục lỗi độc lập và ghi nhận danh tính từng kỹ thuật viên giám định.

Câu hỏi 2: Làm sao để ngăn chặn không cho ai insert vào Inspections khi hợp đồng đang ở trạng thái BOOKED?

Trả lời:
Sử dụng Trigger BEFORE INSERT trên bảng Inspections kết hợp lệnh SIGNAL SQLSTATE '45000'.
Do ràng buộc CHECK của MySQL không hỗ trợ kiểm tra chéo bảng (cross-table check), Trigger là cơ chế phía máy chủ duy nhất bảo đảm 100% toàn vẹn dữ liệu ngay cả khi ứng dụng bị lỗi logic.

Câu hỏi 3: Sự thiếu đồng bộ giữa Activity Diagram và ERD dẫn đến những hậu quả gì về UX trên ứng dụng?

Trả lời:
1. Mất lòng tin: Ứng dụng không hiển thị được bảng phân rã chi tiết khấu trừ (khách không biết vì sao bị trừ 2 triệu, trừ vì lỗi gì).
2. Gãy luồng trải nghiệm: Nhân viên phải lấy giấy bút ghi sổ, gọi điện xin số tài khoản kế toán, giữ chân khách tại bãi xe hàng giờ.
3. Tranh chấp bùng nổ: Thiếu email biên bản kiểm tra tức thời khiến khách khiếu nại ngân hàng (chargeback) và đánh giá 1 sao phá hủy danh tiếng ứng dụng.

Mã Nguồn SQL Hoàn Chỉnh (autoride_db.sql)

-- CREATE DATABASE & TABLES
CREATE DATABASE IF NOT EXISTS autoride_db;
USE autoride_db;

CREATE TABLE Cars (
    car_id INT AUTO_INCREMENT PRIMARY KEY,
    model_name VARCHAR(100) NOT NULL,
    license_plate VARCHAR(20) UNIQUE NOT NULL
);

CREATE TABLE Rentals (
    rental_id INT AUTO_INCREMENT PRIMARY KEY,
    car_id INT NOT NULL,
    customer_name VARCHAR(100) NOT NULL,
    rent_date DATETIME NOT NULL,
    return_date DATETIME,
    status ENUM('BOOKED', 'ACTIVE', 'COMPLETED', 'CANCELLED') NOT NULL DEFAULT 'BOOKED',
    security_deposit DECIMAL(12, 2) NOT NULL DEFAULT 0.00,
    late_fee DECIMAL(12, 2) NOT NULL DEFAULT 0.00,
    damage_fee DECIMAL(12, 2) NOT NULL DEFAULT 0.00,
    CONSTRAINT FK_Rentals_Cars FOREIGN KEY (car_id) REFERENCES Cars(car_id) ON DELETE RESTRICT
);

CREATE TABLE Inspections (
    inspection_id INT AUTO_INCREMENT PRIMARY KEY,
    rental_id INT NOT NULL,
    inspection_date DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    damage_description TEXT,
    inspector_name VARCHAR(100) NOT NULL,
    CONSTRAINT FK_Inspections_Rentals FOREIGN KEY (rental_id) REFERENCES Rentals(rental_id) ON DELETE RESTRICT
);

-- TRIGGER CHẶN INSERT KHI STATUS = BOOKED
DELIMITER //
CREATE TRIGGER before_insert_inspections
BEFORE INSERT ON Inspections
FOR EACH ROW
BEGIN
    DECLARE current_status ENUM('BOOKED', 'ACTIVE', 'COMPLETED', 'CANCELLED');
    SELECT status INTO current_status FROM Rentals WHERE rental_id = NEW.rental_id;
    IF current_status = 'BOOKED' THEN
        SIGNAL SQLSTATE '45000'
        SET MESSAGE_TEXT = 'Loi: Khong the tao bien ban kiem tra xe khi hop dong dang o trang thai BOOKED.';
    END IF;
END //
DELIMITER ;

-- DML SIMULATION: NGUYEN VAN A

INSERT INTO Rentals (car_id, customer_name, rent_date, status, security_deposit, late_fee, damage_fee)
VALUES (1, 'Nguyen Van A', '2026-10-06 08:00:00', 'ACTIVE', 10000000.00, 0.00, 0.00);

SET @current_rental_id = LAST_INSERT_ID();

INSERT INTO Inspections (rental_id, inspection_date, damage_description, inspector_name)
VALUES (@current_rental_id, '2026-10-08 17:00:00', 'Vo den pha trai phia truoc', 'Nhan vien Nguyen Van Kiem');

UPDATE Rentals
SET return_date = '2026-10-08 17:00:00',
    status = 'COMPLETED',
    damage_fee = 2000000.00
WHERE rental_id = @current_rental_id;

-- SELECT QUYẾT TOÁN HOÀN TIỀN
SELECT 
    r.rental_id, r.customer_name, c.model_name, c.license_plate, r.status,
    i.damage_description,
    FORMAT(r.security_deposit, 0) AS Tien_Coc,
    FORMAT(r.damage_fee, 0) AS Phat_Hu_Hong,
    FORMAT(r.security_deposit - r.late_fee - r.damage_fee, 0) AS Tien_Hoan_Tra
FROM Rentals r
JOIN Cars c ON r.car_id = c.car_id
LEFT JOIN Inspections i ON r.rental_id = i.rental_id
WHERE r.rental_id = @current_rental_id;
