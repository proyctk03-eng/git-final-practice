# [Bài tập] Sử dụng thẻ hình ảnh

## 1. Mục tiêu
Luyện tập sử dụng thẻ hiển thị hình ảnh (`<img>`) trong trang web HTML.

## 2. Thông tin sinh viên
- **Học viên**: Nguyễn Tuấn Đạt
- **Bài tập**: Sử dụng thẻ hình ảnh - CodeGym
- **File mã nguồn**: `index.html`

## 3. Nội dung thực hiện
1. Tạo tệp `index.html`.
2. Sử dụng thẻ `<img>` chèn hình ảnh phong cảnh thiên nhiên sắc nét.
3. Thuộc tính `src`: Đường dẫn URL hình ảnh chất lượng cao.
4. Thuộc tính `alt`: Mô tả văn bản chi tiết nội dung bức ảnh ("Phong cảnh núi non hùng vĩ soi bóng xuống mặt hồ nước phẳng lặng").
5. Thuộc tính `width="600"`: Tối ưu kích thước hiển thị cân đối trên trang.
