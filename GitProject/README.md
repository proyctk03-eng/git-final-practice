# GitProject

Dự án thực hành cơ bản với Git và GitHub.

## 1. Giới thiệu dự án
- Bài tập: [Bài tập] Sử dụng Git - CodeGym
- Mục tiêu: Thực hành tạo repository, quản lý file mã nguồn trong thư mục `source`, thực hiện commit và đẩy lên GitHub.

## 2. Thông tin học viên
- Họ và tên: Nguyễn Tuấn Đạt
- Tài khoản GitHub: [proyctk03-eng](https://github.com/proyctk03-eng)
- Repository: https://github.com/proyctk03-eng/GitProject

## 3. Cấu trúc dự án
- `README.md`: Tài liệu mô tả dự án.
- `source/`: Thư mục chứa các tệp mã nguồn:
  - `index.html`: Trang chủ của dự án.
  - `news.html`: Trang tin tức của dự án.
