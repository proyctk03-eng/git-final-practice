# [Bài tập] Định dạng văn bản với HTML Styles

## 1. Mục tiêu
Luyện tập sử dụng CSS nội tuyến (`style`) để định dạng văn bản trong HTML.

## 2. Thông tin sinh viên
- **Học viên**: Nguyễn Tuấn Đạt
- **Bài tập**: Định dạng văn bản với HTML Styles - CodeGym
- **File mã nguồn**: `index.html`

## 3. Nội dung thực hiện
1. Tiêu đề `<h1>`: Màu xanh dương (`color: blue`), nội dung "Bài viết của tôi".
2. Đoạn văn `<p>` 1: Màu đỏ và chữ in đậm (`color: red; font-weight: bold`), nội dung "Đây là đoạn văn được định dạng màu sắc".
3. Đoạn văn `<p>` 2: Chữ in nghiêng và căn giữa (`font-style: italic; text-align: center`), nội dung "Tôi đang học HTML Styles".
4. Đoạn văn `<p>` 3: Kích thước chữ 20px và gạch chân (`font-size: 20px; text-decoration: underline`), nội dung "Định dạng văn bản giúp trang web đẹp hơn".
