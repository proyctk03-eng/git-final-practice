# [Thực hành] Tạo form cơ bản

## 1. Mục tiêu
Luyện tập tạo biểu mẫu (form) trong HTML với các phần tử giao diện cơ bản:
- Thẻ form với phương thức GET: `<form method="get" action="simpleform.html" class="wufoo">`.
- Định dạng kiểu chữ với CSS: `font-family: "Lucida Grande", "Lucida Sans Unicode", Tahoma, sans-serif`.
- Thẻ chọn thả xuống (`<select>`, `<option>`).
- Nút chọn một (`<input type="radio">`).
- Ô nhập dữ liệu văn bản (`<input type="text">`) với các thuộc tính `placeholder`, `size`.
- Nút bấm gửi biểu mẫu (`<input type="button">`).
