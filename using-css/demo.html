Tiến Trình 5 Bước Thực Hành (Interactive Stepper) Bấm chọn từng bước để xem kết quả và mã nguồn

Theo dõi cách tài liệu HTML thay đổi diện mạo qua từng thuộc tính CSS được thêm vào.

Kết Quả Hiển Thị Trong Trình Duyệt (Bước 5)
Mô Hình Hộp CSS (The CSS Box Model) Phân tích cấu trúc vật lý của thẻ <p>

Trong Bước 3 và Bước 4, ta sử dụng border: 1px solid grey; và padding: 10px; để định hình không gian của thẻ đoạn văn.

Margin (Khoảng cách giữa các đoạn văn: mặc định 1em)
Border: 1px solid grey (Đường viền bao bọc phần tử)
Padding: 10px (Khoảng đệm từ viền đến nội dung văn bản)
Content: "Đây là đoạn văn bản." (Kích thước chữ 120%, font Arial)
Cơ Chế Ghi Đè Độ Ưu Tiên (CSS Selector Specificity)

Giải thích tại sao trong Bước 5, đoạn văn bản có id="element1" đổi sang màu xanh dương (blue) thay vì màu đỏ (red) của thẻ p thông thường.

Selector Loại Selector Trọng số ưu tiên (Specificity) Màu chữ áp dụng Kế thừa các thuộc tính khác
p Type Selector (Tag) (0, 0, 1) (Điểm 1) red Áp dụng cho mọi thẻ <p> mặc định
#element1 ID Selector (1, 0, 0) (Điểm 100) blue Ghi đè thuộc tính color vì có độ ưu tiên cao hơn 100 lần so với Type Selector. Vẫn kế thừa font-family, font-size, border và padding của thẻ p.
Thử Nghiệm Tùy Biến CSS (Live CSS Playground) Thay đổi tham số để quan sát trực tiếp

Tự do điều chỉnh giá trị thuộc tính để hiểu sâu hơn về cơ chế hiển thị CSS.
