Kiến trúc và cơ chế thực thi Stored Procedure

Ưu điểm của Stored Procedure

  • Biên dịch sẵn (Pre-compiled): Lưu trữ kế hoạch thực thi trong bộ nhớ đệm (Plan Cache), chạy nhanh hơn các truy vấn SQL thô.
  • Tiết kiệm băng thông mạng: Ứng dụng chỉ truyền chuỗi lệnh ngắn (như CALL findAllCustomers();) thay vì gửi toàn bộ khối SQL dài.
  • Đóng gói nghiệp vụ & Bảo mật: Cấp quyền thực thi EXECUTE cho người dùng mà không cần mở quyền trực tiếp trên bảng dữ liệu gốc.
  • Phòng chống SQL Injection: Khi sử dụng tham số hóa, ngăn chặn mã độc can thiệp vào câu lệnh truy vấn.

Nhược điểm & Lưu ý kỹ thuật

  • Chiếm dụng RAM máy chủ: Quá nhiều thủ tục sẽ tiêu tốn dung lượng bộ nhớ đệm của DB Server.
  • Gia tăng tải CPU cho CSDL: Không nên nhồi nhét xử lý vòng lặp nặng nề vào DB Server; nên phân tách logic về tầng ứng dụng.
  • Khó khăn khi Debug: MySQL không có công cụ gỡ lỗi từng bước (Step-by-step debugger) mạnh mẽ như Oracle hay SQL Server.
  • Không có ALTER PROCEDURE sửa thân thủ tục: Bắt buộc phải dùng cơ chế xóa và tạo lại (DROP IF EXISTS → CREATE PROCEDURE).

Thực hành triển khai Stored Procedure từng bước

Giải thích từ khóa quan trọng:
- DELIMITER //: Đổi ký tự kết thúc câu lệnh từ ; thành // để client không kết thúc sớm khi gặp dấu ; bên trong thân thủ tục.
- CREATE PROCEDURE findAllCustomers(): Định nghĩa tên thủ tục.
- BEGIN ... END //: Khối lệnh thực thi nghiệp vụ bên trong.
- DELIMITER ;: Trả lại ký tự phân cách về dấu chấm phẩy mặc định.
MySQL Query - Tạo và triệu gọi findAllCustomers() 
DELIMITER //

CREATE PROCEDURE findAllCustomers()
BEGIN
    SELECT * FROM customers;
END //

DELIMITER ;

-- Triệu gọi Stored Procedure
CALL findAllCustomers();

Quy tắc cập nhật thủ tục trong MySQL (Drop & Re-create):
MySQL không hỗ trợ ALTER PROCEDURE để sửa đổi các câu lệnh SQL bên trong BEGIN...END. Vì vậy, ta áp dụng lệnh DROP PROCEDURE IF EXISTS để xóa thủ tục cũ trước, sau đó tạo lại thủ tục mới với điều kiện lọc customerNumber = 175.
MySQL Script - Sửa Stored Procedure bằng Drop & Re-create 
DELIMITER //

DROP PROCEDURE IF EXISTS `findAllCustomers` //

CREATE PROCEDURE findAllCustomers()
BEGIN
    SELECT * FROM customers WHERE customerNumber = 175;
END //

DELIMITER ;

-- Triệu gọi lại sau khi sửa
CALL findAllCustomers();

Mở rộng: Stored Procedure có tham số truyền vào (IN Parameter):
Thay vì cố định cứng mã khách hàng 175, ta truyền tham số IN p_customerNumber INT. Điều này giúp thủ tục trở nên tái sử dụng linh hoạt cho bất kỳ khách hàng nào.
MySQL Script - Stored Procedure với tham số IN 
DELIMITER //

DROP PROCEDURE IF EXISTS `getCustomerById` //

CREATE PROCEDURE getCustomerById(IN p_customerNumber INT)
BEGIN
    SELECT * 
    FROM customers 
    WHERE customerNumber = p_customerNumber;
END //

DELIMITER ;

-- Triệu gọi với tham số động
CALL getCustomerById(175);
CALL getCustomerById(103);

DELIMITER //
CREATE PROCEDURE findAllCustomers()
BEGIN
    SELECT * FROM customers;
END //
DELIMITER ;

-- 3. GOI PROCEDURE
CALL findAllCustomers();

-- 4. SUA PROCEDURE (DROP & RE-CREATE)
DELIMITER //
DROP PROCEDURE IF EXISTS `findAllCustomers` //
CREATE PROCEDURE findAllCustomers()
BEGIN
    SELECT * FROM customers WHERE customerNumber = 175;
END //
DELIMITER ;

-- 5. GOI LAI PROCEDURE SAU KHI CAP NHAT
CALL findAllCustomers();

-- 6. PROCEDURE CO THAM SO (IN PARAMETER)
DELIMITER //
DROP PROCEDURE IF EXISTS `getCustomerById` //
CREATE PROCEDURE getCustomerById(IN p_customerNumber INT)
BEGIN
    SELECT * FROM customers WHERE customerNumber = p_customerNumber;
END //
DELIMITER ;
