Bước 1: Liệt kê, chọn lọc thông tin

Thông tin Đơn đặt hàng

  • Số đơn hàng (Số ĐH): Khóa nhận diện đơn
  • Tên đơn vị đặt hàng (Tên ĐV)
  • Địa chỉ, Điện thoại
  • Ngày đặt
  • Tên hàng, Mô tả, Đơn vị tính (Đv tính)
  • Số lượng đặt
  • Người đặt hàng (Họ tên NĐ)

Thông tin Phiếu giao hàng

  • Số phiếu giao hàng (Số PG): Khóa nhận diện phiếu giao
  • Tên đơn vị đặt hàng, Địa chỉ
  • Nơi giao hàng (Tên nơi GH)
  • Ngày giao
  • Tên hàng, Đv tính, Số lượng
  • Đơn giá, Thành tiền
  • Tên người nhận (Họ tên NN), Người giao (Họ tên NG)

Bước 2: Xác định thực thể và thuộc tính ban đầu

Tên thực thể Thuộc tính khóa (PK) Các thuộc tính mô tả
ĐƠN VỊ ĐH Mã ĐV Tên ĐV, Địa chỉ, Điện thoại
ĐƠN VỊ KH Mã ĐV Tên ĐV, Địa chỉ
HÀNG Mã hàng Tên hàng, Đv tính, Mô tả hàng
NGƯỜI ĐẶT Mã số NĐ Họ tên NĐ
NƠI GIAO Mã số ĐĐG Tên nơi giao
NGƯỜI NHẬN Mã số NN Họ tên NN
NGƯỜI GIAO Mã số NG Họ tên NG

Bước 3: Xác định các mối quan hệ

  • Quan hệ THUỘC (1 - N): Người đặt hàng THUỘC Đơn vị đặt hàng.
  • Quan hệ THUỘC (1 - N): Người nhận hàng THUỘC Đơn vị khách hàng.
  • Quan hệ ĐẶT: Người đặt hàng tiến hành ĐẶT các mặt Hàng (chứa các thuộc tính: Số ĐH, Ngày đặt, Số lượng).
  • Quan hệ GIAO: Người giao tiến hành GIAO Hàng cho Người nhận tại Nơi giao (chứa các thuộc tính: Số PG, Ngày giao, Số lượng, Đơn giá, Thành tiền).

Bước 4: Vẽ biểu đồ mô hình thực thể ERD

Vẽ sơ đồ ERD dựa trên tập thực thể và mối quan hệ xác định ở Bước 2 và Bước 3.

Bước 5: Chuẩn hóa, rút gọn mô hình thực thể ERD

Do Đơn vị đặt hàng và Đơn vị khách hàng đều là các đối tác bên ngoài giao dịch với cửa hàng, ta hợp nhất thành một thực thể duy nhất: ĐƠN VỊ KHÁCH gồm các thuộc tính:

  • Mã ĐV (PK): Mã định danh đơn vị
  • Tên ĐV: Tên đơn vị khách hàng
  • Địa chỉ: Địa chỉ trụ sở
  • Điện thoại: Số điện thoại liên hệ

Cả NGƯỜI ĐẶT và NGƯỜI NHẬN đều trực thuộc thực thể ĐƠN VỊ KHÁCH qua khóa ngoại MaDV.

Mã nguồn DDL khởi tạo Cơ sở dữ liệu chuẩn hóa (schema.sql)

Tương thích hoàn toàn với hệ quản trị cơ sở dữ liệu MySQL, PostgreSQL và Microsoft SQL Server:

-- 1. BANG DANH MUC (MASTER TABLES)
CREATE TABLE DON_VI_KHACH (
    MaDV VARCHAR(20) NOT NULL PRIMARY KEY,
    TenDV NVARCHAR(100) NOT NULL,
    DiaChi NVARCHAR(200),
    DienThoai VARCHAR(20)
);

CREATE TABLE NGUOI_DAT (
    MaND VARCHAR(20) NOT NULL PRIMARY KEY,
    HoTenND NVARCHAR(100) NOT NULL,
    MaDV VARCHAR(20) NOT NULL,
    CONSTRAINT FK_NguoiDat_DonViKhach FOREIGN KEY (MaDV) REFERENCES DON_VI_KHACH(MaDV)
);

CREATE TABLE NGUOI_NHAN (
    MaNN VARCHAR(20) NOT NULL PRIMARY KEY,
    HoTenNN NVARCHAR(100) NOT NULL,
    MaDV VARCHAR(20) NOT NULL,
    CONSTRAINT FK_NguoiNhan_DonViKhach FOREIGN KEY (MaDV) REFERENCES DON_VI_KHACH(MaDV)
);

CREATE TABLE NGUOI_GIAO (
    MaNG VARCHAR(20) NOT NULL PRIMARY KEY,
    HoTenNG NVARCHAR(100) NOT NULL
);

CREATE TABLE NOI_GIAO (
    MaDDG VARCHAR(20) NOT NULL PRIMARY KEY,
    TenNoiGiao NVARCHAR(200) NOT NULL
);

CREATE TABLE HANG_HOA (
    MaHang VARCHAR(20) NOT NULL PRIMARY KEY,
    TenHang NVARCHAR(100) NOT NULL,
    DvTinh NVARCHAR(50) NOT NULL,
    MoTaHang NVARCHAR(MAX)
);

-- 2. BANG GIAO DICH (TRANSACTION TABLES)
CREATE TABLE DON_DAT_HANG (
    SoDH VARCHAR(20) NOT NULL PRIMARY KEY,
    NgayDat DATE NOT NULL,
    MaND VARCHAR(20) NOT NULL,
    CONSTRAINT FK_DonDatHang_NguoiDat FOREIGN KEY (MaND) REFERENCES NGUOI_DAT(MaND)
);

CREATE TABLE CHI_TIET_DAT_HANG (
    SoDH VARCHAR(20) NOT NULL,
    MaHang VARCHAR(20) NOT NULL,
    SoLuongDat INT NOT NULL CHECK (SoLuongDat > 0),
    PRIMARY KEY (SoDH, MaHang),
    CONSTRAINT FK_CTDH_DonDatHang FOREIGN KEY (SoDH) REFERENCES DON_DAT_HANG(SoDH),
    CONSTRAINT FK_CTDH_HangHoa FOREIGN KEY (MaHang) REFERENCES HANG_HOA(MaHang)
);

CREATE TABLE PHIEU_GIAO_HANG (
    SoPG VARCHAR(20) NOT NULL PRIMARY KEY,
    NgayGiao DATE NOT NULL,
    SoDH VARCHAR(20) NOT NULL,
    MaNG VARCHAR(20) NOT NULL,
    MaNN VARCHAR(20) NOT NULL,
    MaDDG VARCHAR(20) NOT NULL,
    CONSTRAINT FK_PhieuGiao_DonDatHang FOREIGN KEY (SoDH) REFERENCES DON_DAT_HANG(SoDH),
    CONSTRAINT FK_PhieuGiao_NguoiGiao FOREIGN KEY (MaNG) REFERENCES NGUOI_GIAO(MaNG),
    CONSTRAINT FK_PhieuGiao_NguoiNhan FOREIGN KEY (MaNN) REFERENCES NGUOI_NHAN(MaNN),
    CONSTRAINT FK_PhieuGiao_NoiGiao FOREIGN KEY (MaDDG) REFERENCES NOI_GIAO(MaDDG)
);

CREATE TABLE CHI_TIET_GIAO_HANG (
    SoPG VARCHAR(20) NOT NULL,
    MaHang VARCHAR(20) NOT NULL,
    SoLuongGiao INT NOT NULL CHECK (SoLuongGiao > 0),
    DonGiaGiao DECIMAL(18, 2) NOT NULL CHECK (DonGiaGiao >= 0),
    ThanhTien DECIMAL(18, 2) NOT NULL,
    PRIMARY KEY (SoPG, MaHang),
    CONSTRAINT FK_CTGH_PhieuGiao FOREIGN KEY (SoPG) REFERENCES PHIEU_GIAO_HANG(SoPG),
    CONSTRAINT FK_CTGH_HangHoa FOREIGN KEY (MaHang) REFERENCES HANG_HOA(MaHang)
);
