# [Bài tập] Tạo liên kết trong HTML

## 1. Mục tiêu
Luyện tập sử dụng thẻ liên kết (`<a>`) để điều hướng giữa các trang web, mở tab mới, liên kết nội bộ và liên kết gửi email.

## 2. Thông tin sinh viên
- **Học viên**: Nguyễn Tuấn Đạt
- **Bài tập**: Tạo liên kết trong HTML - CodeGym
- **File mã nguồn**: `index.html`, `about.html`

## 3. Nội dung thực hiện
1. **Tiêu đề `<h1>`**: "Liên kết yêu thích của tôi".
2. **Danh sách không thứ tự (`<ul>`)**: 3 liên kết ngoài (Google, GitHub, Wikipedia).
3. **Mở tab mới (`target="_blank"`)**: Thuộc tính `target="_blank"` kèm `rel="noopener noreferrer"`.
4. **Liên kết nội bộ**: Liên kết đến tệp `about.html` trong cùng thư mục.
5. **Liên kết email (`mailto:`)**: `<a href="mailto:proyctk03@gmail.com">`.
